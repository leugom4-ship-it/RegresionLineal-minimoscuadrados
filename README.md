Descripción

Este programa implementa el método de regresión lineal por mínimos cuadrados utilizando Java.

Calcula los siguientes valores:

- Pendiente (beta1).
- Ordenada al origen (beta0).
- Coeficiente de correlación de Pearson (r).
- Coeficiente de determinación (r²).
- Predicción de valores.

Datos de prueba

X = {1, 2, 3, 4, 5}

Y = {2, 3, 5, 4, 6}

Resultados esperados

- Pendiente: 0.9000
- Ordenada: 1.3000
- Pearson: 0.9000
- Determinación r²: 0.8100
- Predicción para X=6: 6.7000

Cómo ejecutar el programa

1. Descargar o clonar este repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Ejecutar la clase "RegresionLineal.java".
4. Consultar los resultados en la consola.
